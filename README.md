# Integration Cost Calculator

Student prototype for BUS 365 (Emory University), Digitas case competition. Not an official Digitas tool.

Compares several specialist agencies with one integrated partner over 5 to 15 years: agency reviews, handover overlap and coordination time, with every default sourced or labelled as assumed. Formulas and sources are on the "How it works" page.

This repo holds the published page only.
